# 題目：報價單生成器
角色：鋅合金產品業務。

痛點：報價速度太慢。

目的：正式報價速度太慢，一般需要等供應商報價後，我們才能整合供應商與廠內製程來報價，因此需要能初步報價的系統來加速報價，成品單價主要以有以下製程價格組成，原料價格/壓鑄/加工/拋光/表面處理/其他費用。

 1.原料價格的選區填選：每公斤的價格以及成品重量來計算。
 2.壓鑄價格的選區填選：物件長寬高的大小以及模具穴數。
 3.加工價格的選需填寫：加工種類。
 4.拋光價格的選區填寫：物件長寬高的大小以及細拋光還是粗拋光。
 5.表面處理價格的選區填寫：表面處理種類以及物件長寬高的大小。
 6.其他費用的選區可以自行新增其他種類的費用。

Final：最後可將報價單輸出
